Aphiwataras — Live Order Flow - web app package (made with aphiwat htmlTOapp)

1. Upload this whole folder to an HTTPS host (GitHub Pages, Netlify, Cloudflare Pages, or your own server).
2. Open the web address in Safari on iPhone or iPad.
3. Tap Share, then Add to Home Screen. Keep Open as Web App on, then tap Add.
4. Android Chrome: open the menu, then Install app.

Files
  index.html            your page with the web app tags added
  manifest.webmanifest  name, colors, display mode and icons
  sw.js                 offline cache (only if enabled)
  icons/                home screen icons
  splash/               iOS launch screens (only if enabled)

After you change index.html, upload it again. If the old version still shows, close the app and reopen it once.
